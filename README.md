## Bachelor's thesis, with ABB (grade A)

**Simulation-Based Testing Framework for Embedded Systems Using MQTT and Cross-Compiled Code**

A virtual ABB IPS controller drives a simulated RLC circuit instead of real hardware. A C# proxy reads the controller's
shared memory and publishes setpoints over MQTT, and a Python simulator sends the measurement back.
Mean round-trip latency: **7.0 ms** over 1000 samples. I built the proxy layer and ran the latency measurements.
